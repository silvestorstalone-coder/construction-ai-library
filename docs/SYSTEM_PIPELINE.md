# SYSTEM_PIPELINE.md

## Архитектура AI pipeline

### Основные компоненты

AI pipeline состоит из следующих компонентов:

1. **Data Ingestion (Сбор данных)**: модуль для сбора и предварительной обработки данных, необходимых для обучения и тестирования моделей.
2. **Feature Engineering (Разработка признаков)**: модуль для создания и преобразования признаков, которые будут использоваться моделями.
3. **Model Training (Обучение моделей)**: модуль для обучения моделей на основе собранных данных.
4. **Model Evaluation (Оценка моделей)**: модуль для оценки производительности моделей и выбора наилучших.
5. **Deployment (Развёртывание)**: модуль для развёртывания моделей в производственной среде.
6. **Monitoring (Мониторинг)**: модуль для мониторинга производительности и состояния моделей в производственной среде.

### Взаимодействие компонентов

Компоненты взаимодействуют друг с другом через API и файловую систему. Данные передаются между компонентами в формате JSON или CSV.

## GitHub Actions

GitHub Actions используется для автоматизации процессов разработки и развёртывания. Основные действия включают:

- **Сборка (Build)**: сборка кода и подготовка его к развёртыванию.
- **Тестирование (Test)**: запуск тестов для проверки корректности работы кода.
- **Развёртывание (Deploy)**: развёртывание кода в производственной среде.

### Конфигурация

Конфигурация GitHub Actions осуществляется через файлы `yml` в репозитории. В этих файлах указываются действия, триггеры и параметры.

## YandexGPT integration

YandexGPT интегрируется в AI pipeline для генерации текста и улучшения качества данных. Основные шаги интеграции:

1. **Получение API ключа**: получение ключа для доступа к API YandexGPT.
2. **Настройка окружения**: настройка окружения для работы с API.
3. **Интеграция в модули**: интеграция YandexGPT в модули сбора данных и разработки признаков.

## Структура модулей

Модули организованы в виде директорий с соответствующими файлами. Каждый модуль содержит:

- `main.py`: основной файл модуля.
- `config.yml`: файл конфигурации модуля.
- `tests`: директория с тестами для модуля.

## CI/CD поток

CI/CD поток включает следующие этапы:

1. **Сборка (Build)**: сборка кода и подготовка его к развёртыванию.
2. **Тестирование (Test)**: запуск тестов для проверки корректности работы кода.
3. **Развёртывание (Deploy)**: развёртывание кода в производственной среде.
4. **Мониторинг (Monitor)**: мониторинг производительности и состояния моделей в производственной среде.

Каждый этап выполняется автоматически при изменении кода в репозитории.
