# SYSTEM_PIPELINE.md

## Архитектура AI pipeline

### Основные компоненты

AI pipeline состоит из следующих основных компонентов:

1. **Data Ingestion (Сбор данных)**: модуль для сбора и предварительной обработки данных, необходимых для обучения и тестирования моделей.
2. **Feature Engineering (Разработка признаков)**: модуль для создания и преобразования признаков, которые будут использоваться моделями.
3. **Model Training (Обучение моделей)**: модуль для обучения моделей на основе собранных данных.
4. **Model Evaluation (Оценка моделей)**: модуль для оценки производительности моделей и выбора наилучших.
5. **Deployment (Развёртывание)**: модуль для развёртывания моделей в продуктивной среде.
6. **Monitoring (Мониторинг)**: модуль для мониторинга производительности и состояния моделей в реальном времени.

### Взаимодействие компонентов

Компоненты взаимодействуют друг с другом через API и файловые системы. Данные передаются между модулями в формате JSON или CSV.

## GitHub Actions

GitHub Actions используется для автоматизации процессов разработки и развёртывания. Основные этапы CI/CD потока:

1. **Pull Request (PR)**: при создании PR запускается автоматизированный процесс проверки кода.
2. **Code Review (Проверка кода)**: выполняются статический анализ кода и тесты.
3. **Build (Сборка)**: собирается артефакт (например, Docker-образ) для развёртывания.
4. **Test (Тестирование)**: выполняются тесты для проверки функциональности.
5. **Deploy (Развёртывание)**: артефакт развёртывается в тестовой или продуктивной среде.

## YandexGPT integration

YandexGPT интегрируется в AI pipeline для генерации текста и улучшения качества данных. Основные шаги интеграции:

1. **API вызов**: модуль Data Ingestion вызывает API YandexGPT для генерации текста или улучшения данных.
2. **Обработка ответа**: ответ от API обрабатывается и интегрируется в данные.
3. **Использование в моделировании**: обработанные данные используются в модуле Model Training для обучения моделей.

## Структура модулей

Модули организованы в виде директорий с соответствующими файлами и скриптами. Основные директории:

- `data`: содержит скрипты и файлы для сбора и обработки данных.
- `models`: содержит модели и скрипты для обучения и оценки.
- `deploy`: содержит скрипты для развёртывания моделей.
- `monitoring`: содержит скрипты для мониторинга моделей.

## CI/CD поток

CI/CD поток включает в себя следующие этапы:

1. **Code Commit (Коммит кода)**: код коммитится в репозиторий GitHub.
2. **GitHub Actions Trigger (Запуск GitHub Actions)**: при коммите запускается соответствующий workflow в GitHub Actions.
3. **Build and Test (Сборка и тестирование)**: выполняются сборка и тестирование артефакта.
4. **Deploy (Развёртывание)**: артефакт развёртывается в тестовой среде.
5. **Monitor (Мониторинг)**: модели мониторятся в тестовой среде.
6. **Feedback Loop (Обратная связь)**: результаты мониторинга и тестирования используются для улучшения кода и моделей.

Каждый этап может быть настроен и модифицирован в соответствии с требованиями проекта.
