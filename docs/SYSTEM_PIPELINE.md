# SYSTEM_PIPELINE.md

## Архитектура AI pipeline

### Основные компоненты

1. **Data Ingestion (Приём данных)**: модуль для сбора и предварительной обработки данных, необходимых для обучения и тестирования моделей.
2. **Feature Engineering (Разработка признаков)**: создание и преобразование признаков для улучшения качества моделей.
3. **Model Training (Обучение моделей)**: модуль для обучения моделей на основе предоставленных данных.
4. **Model Evaluation (Оценка моделей)**: оценка производительности моделей с использованием различных метрик.
5. **Deployment (Развёртывание)**: модуль для развёртывания обученных моделей в продуктивной среде.
6. **Monitoring and Logging (Мониторинг и логирование)**: отслеживание состояния и производительности системы.

### Интеграции

- **GitHub Actions**: используется для автоматизации CI/CD процессов, включая сборку, тестирование и развёртывание.
- **YandexGPT integration**: интеграция с YandexGPT для генерации текста и улучшения качества данных.

## GitHub Actions

GitHub Actions позволяет автоматизировать рабочие процессы в репозиториях GitHub. В нашем AI pipeline GitHub Actions используется для:

- **Сборка проекта**: автоматическая сборка проекта при каждом коммите в репозиторий.
- **Тестирование**: запуск тестов при каждом коммите для обеспечения качества кода.
- **Развёртывание**: автоматическое развёртывание изменений в продуктивной среде после успешного прохождения тестов.

## YandexGPT integration

Интеграция с YandexGPT позволяет использовать возможности модели для генерации текста и улучшения качества данных. Это может быть полезно для:

- **Автоматизации создания описаний данных**: генерация описаний для наборов данных, используемых в обучении моделей.
- **Улучшения качества данных**: использование модели для исправления ошибок и улучшения качества текстовых данных.

## Структура модулей

- **data_ingestion.py**: модуль для сбора и предварительной обработки данных.
- **feature_engineering.py**: модуль для создания и преобразования признаков.
- **model_training.py**: модуль для обучения моделей.
- **model_evaluation.py**: модуль для оценки производительности моделей.
- **deployment.py**: модуль для развёртывания моделей.
- **monitoring.py**: модуль для мониторинга состояния системы.

## CI/CD поток

1. **Коммит в репозиторий**: разработчик совершает изменения в коде и совершает коммит.
2. **GitHub Actions**: GitHub Actions запускает сборку и тестирование проекта.
3. **Сборка и тестирование**: проект собирается и тестируется.
4. **Успешное прохождение тестов**: если тесты пройдены успешно, GitHub Actions запускает развёртывание изменений в продуктивной среде.
5. **Развёртывание**: изменения развёртываются в продуктивной среде.
6. **Мониторинг**: после развёртывания система мониторится для обеспечения её стабильной работы.
