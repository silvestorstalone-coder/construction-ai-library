# SYSTEM_PIPELINE.md

## Архитектура AI pipeline

### Основные компоненты

1. **Data Ingestion (Сбор данных)**: модуль для сбора и предварительной обработки данных, необходимых для обучения и тестирования моделей AI.
2. **Feature Engineering (Разработка признаков)**: модуль для создания и преобразования признаков, которые будут использоваться моделями.
3. **Model Training (Обучение моделей)**: модуль для обучения моделей AI на подготовленных данных.
4. **Model Evaluation (Оценка моделей)**: модуль для оценки производительности обученных моделей.
5. **Deployment (Развёртывание)**: модуль для развёртывания моделей в продуктивной среде.
6. **Monitoring (Мониторинг)**: модуль для мониторинга производительности и состояния моделей в реальном времени.

### Взаимодействие компонентов

Компоненты взаимодействуют друг с другом через API и файловую систему. Данные передаются между модулями в формате JSON или CSV.

## GitHub Actions

Для автоматизации CI/CD процесса используется GitHub Actions. Конвейеры настроены для выполнения следующих задач:

- **Сборка (Build)**: сборка проекта и подготовка его к развёртыванию.
- **Тестирование (Test)**: запуск тестов для проверки корректности работы проекта.
- **Деплоймент (Deploy)**: развёртывание проекта в выбранной среде.

Конвейеры могут быть настроены для выполнения на разных этапах разработки, например, при каждом коммите в репозиторий или при создании новой ветки.

## YandexGPT integration

Для интеграции с YandexGPT используется соответствующий API. Модуль Feature Engineering может использовать YandexGPT для генерации текстовых описаний на основе входных данных. Модуль Model Training может использовать YandexGPT для предварительной обработки текстовых данных перед обучением моделей.

## Структура модулей

Каждый модуль представляет собой отдельный репозиторий или директорию в проекте. Модули могут быть организованы в виде дерева, где каждый модуль зависит от одного или нескольких других модулей.

Например, модуль Data Ingestion может зависеть от модуля Feature Engineering, который, в свою очередь, может зависеть от модуля Model Training.

## CI/CD поток

CI/CD поток включает в себя следующие этапы:

1. **Сборка (Build)**: проект собирается и подготавливается к развёртыванию.
2. **Тестирование (Test)**: проект проходит тестирование для проверки его корректности.
3. **Развёртывание (Deploy)**: проект развёртывается в выбранной среде.
4. **Мониторинг (Monitor)**: после развёртывания проект мониторится для обеспечения его стабильной работы.

Конвейеры GitHub Actions настроены для выполнения этих этапов в автоматическом режиме.
